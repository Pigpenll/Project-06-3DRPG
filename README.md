# Project-06

# Features added
- Third person animated character!
- Terrain and objects!
- A lovely PBR grass texture!
- Three orcs with an AI for the player to kill!
- A friend to have a conversation with!
- A flashlight attached to the character's helmet that they can turn on and off!
- A score for the orcs you slay!
- A clear objective! (Kill the orcs)
- A battery life mechanic for the flashlight for a little bit of juiciness!
- A nice looking environment with ambient lighting!
